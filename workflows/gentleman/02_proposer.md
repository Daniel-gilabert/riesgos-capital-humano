# Phase 02 - Proposer

## Mission

Diseñar plan corto, seguro y verificable antes de ejecutar cambios.

## Inputs

- salida de Explorer

## Tasks

1. proponer pasos pequenos
2. definir validaciones por paso
3. marcar puntos HITL (si hay riesgo)

## Output contract

- `Plan`: pasos 1..N
- `Validation`: como se valida cada paso
- `HITL Gates`: donde se requiere aprobacion humana
- `Rollback`: como volver atras si falla
